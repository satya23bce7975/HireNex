# HireNex Evaluation Benchmark

This folder contains the ground-truth labels and recruiter queries used by the Evaluation Center.

## Files

- `ground_truth.json` — 90 synthetic CSE/ECE/MECH candidate records
- `recruiter_queries.json` — 12 recruiter queries with expected candidate IDs
- `latest_evaluation.json` — generated automatically after running the benchmark

The current benchmark is intended for system-development and academic experimentation. For final publication or capstone reporting, validate the ground truth with a manually reviewed dataset and report the dataset size, annotation protocol, and limitations.
